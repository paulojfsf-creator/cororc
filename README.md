# Coro Litúrgico 5.0

Versão com biblioteca musical e preparação de programas.

## Novidades
- Pesquisa de cânticos por título, autor, tema, momento litúrgico e celebração.
- Sugestões baseadas na celebração concreta e no Salmo oficial.
- Fontes de referência: Secretariado Nacional de Liturgia, Laudate, O Canto na Liturgia e Cantólico.
- Letras já existentes no catálogo são associadas automaticamente ao programa.
- Visualização integrada de partituras locais/directas em PDF ou imagem, quando existe URL de ficheiro.
- Dossier de programa com letras disponíveis, autores e ligações para partituras/fontes.
- Partilha por WhatsApp e email.

## Nota sobre fontes externas
A aplicação estática não deve copiar automaticamente letras ou partituras protegidas a partir de sites externos. Quando uma fonte externa não permite incorporação directa, é apresentado o acesso à fonte. As partituras próprias do coro/ficheiros com URL directo podem ser visualizadas dentro da aplicação.
