# Coro Litúrgico — versão 4.5

Correções e melhorias desta versão:
- Ano litúrgico calculado dinamicamente pelo início do Advento; 25/12/2026 é Ano B.
- Seleção dos momentos da celebração: apenas as secções escolhidas aparecem no programa.
- Botão de preenchimento sugerido com contraste corrigido.
- Gestão de salmistas e organistas com adição, remoção e seleção no programa.
- Compatibilidade mantida com histórico, catálogo, assistente e editor A4.
