# Coro Litúrgico 8.0 — Reorganização e foco no Assistente

Versão de reorganização da aplicação. O objetivo é tornar imediatamente visível o fluxo principal:

**Calendário → Assistente Litúrgico → Programa → Ensaio/Celebração → Histórico**

Áreas principais:
- Início
- Calendário
- Assistente
- Programas
- Repertório
- Coro
- Mais (funções secundárias)

As funcionalidades existentes de ficha, editor, preferências, reconciliação, folhetos, partituras, vídeos e diagnóstico são mantidas, mas retiradas da navegação principal quando são secundárias.
